# [HU-05] Administrar catálogos, planes e intervalos de mantenimiento preventivo

**Dado:** Administrador autorizado.
**Para:** configurar planes, actividades e intervalos de mantenimiento preventivo.
**Que:** mantener las recomendaciones de mantenimiento ajustadas a los tipos de vehículo y uso.

**Flujo esperado**
1. El administrador consulta los planes e intervalos disponibles.
2. El sistema valida los campos y la relación entre plan, vehículo e intervalo.
3. La configuración válida se persiste.
4. MOD-06 consulta los planes vigentes para generar alertas y gestionar citas.

**Criterios de aceptación**
- [ ] Los intervalos deben tener valores válidos y unidades identificables (`KM`, `DIAS`, `MESES`).
- [ ] No se aceptan planes incompletos ni referencias a categorías inexistentes.
- [ ] Los cambios válidos quedan disponibles para MOD-06.
- [ ] No se elimina un plan que tenga citas o mantenimientos relacionados.

**Endpoint:** `GET /api/v1/parametros/planes-mantenimiento` ; `POST /api/v1/parametros/planes-mantenimiento` ; `PUT /api/v1/parametros/planes-mantenimiento/{planId}` ; `DELETE /api/v1/parametros/planes-mantenimiento/{planId}`

**Ejemplo de solicitud**
_POST /parametros/planes-mantenimiento_
```json
{
  "nombre": "Plan preventivo vehículo liviano",
  "categoriaId": "CAT-01",
  "actividades": [
    "Cambio de aceite",
    "Revisión de frenos"
  ],
  "intervalo": {
    "valor": 5000,
    "unidad": "KM"
  }
}
```
_PUT /parametros/planes-mantenimiento/{planId}_
```json
{
  "nombre": "Plan preventivo vehículo liviano",
  "categoriaId": "CAT-01",
  "actividades": [
    "Cambio de aceite",
    "Revisión de frenos"
  ],
  "intervalo": {
    "valor": 5000,
    "unidad": "KM"
  },
  "activo": true
}
```

**Respuesta exitosa**
```json
{
  "exito": true,
  "mensaje": "Catálogo de planes de mantenimiento consultado exitosamente",
  "datos": [
    {
      "planId": "PM-01",
      "nombre": "Plan preventivo vehículo liviano",
      "categoriaId": "CAT-01",
      "actividades": [
        "Cambio de aceite",
        "Revisión de frenos"
      ],
      "intervalo": {
        "valor": 5000,
        "unidad": "KM"
      },
      "activo": true
    }
  ],
  "fechaHora": "2026-10-23T12:00:00-05:00"
}
```

**Notas técnicas:** Rutas, campos y mensajes son propuesta del equipo; se confirman en el Inventario de APIs (punto 4). Las unidades de intervalo `KM`, `DIAS` y `MESES` son propuesta del equipo. El catálogo de mantenimiento es independiente del tarifario.

**Errores específicos de esta historia**

| Código | Cuándo ocurre | Mensaje (`mensaje`) |
|---|---|---|
| 422 Unprocessable Entity | Duplicado por `nombre` o eliminación de un elemento con dependencias activas (citas o mantenimientos registrados en MOD-06). | No es posible completar la operación: el elemento está duplicado o en uso |
| 422 Unprocessable Entity | Intervalo no positivo, unidad no reconocida o categoría inexistente. | Valor inválido en el campo indicado |

## Elementos comunes
### Sobre estándar de respuesta (todas las APIs)

Campos: `exito` (boolean), `mensaje` (string), `datos` (objeto, arreglo o `null`), `fechaHora` (ISO 8601 con zona horaria). El cuerpo no sustituye el código HTTP. Todas las APIs usan `Content-Type: application/json` en operaciones con body y `Authorization: Bearer <JWT>` (salvo registro, login y el webhook de la pasarela, que se autentica con su firma).
