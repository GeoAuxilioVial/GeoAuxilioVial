# [HU-13] Consultar historial integral de servicios mecánicos e indicador de kilometraje acumulado

**Dado:** Propietario de un vehículo autenticado.
**Para:** consultar los datos, estado e historial del vehículo.
**Que:** tomar decisiones informadas antes de solicitar asistencia o mantenimiento.

**Flujo esperado**
1. El usuario solicita el detalle por identificador.
2. El servicio valida token y propiedad o permiso administrativo.
3. Consulta datos del vehículo, historial de servicios y mantenimientos permitidos.
4. Devuelve la información ordenada y paginable si el historial es extenso.

**Criterios de aceptación**
- [ ] Solo el propietario o rol autorizado consulta el detalle.
- [ ] Un vehículo sin historial devuelve arreglos vacíos, no un error de servidor.
- [ ] Los estados se devuelven desde registros persistidos.
- [ ] Los identificadores inexistentes devuelven 404.
- [ ] La respuesta no expone información de terceros.

**Endpoint:** `GET /api/v1/vehiculos/{vehiculoId}` ; `GET /api/v1/vehiculos/{vehiculoId}/historial`

**Ejemplo de solicitud**
```json
{
  "pathParam": {
    "vehiculoId": "veh_789"
  },
  "query": {
    "pagina": 1,
    "limite": 20
  }
}
```

**Respuesta exitosa**
```json
{
  "exito": true,
  "mensaje": "Hoja de vida consultada",
  "datos": {
    "vehiculo": {
      "id": "veh_789",
      "placa": "ABC123",
      "estado": "ACTIVO",
      "kilometraje": 45000
    },
    "servicios": [],
    "mantenimientos": [],
    "paginacion": {
      "pagina": 1,
      "limite": 20,
      "total": 0
    }
  },
  "fechaHora": "2026-10-23T12:00:00-05:00"
}
```

**Notas técnicas:** limitar tamaño de página, validar límites y evitar consultas sin índice sobre historial.

**Requisitos de pruebas**

| Caso | Precondición | Acción exacta | Resultado esperado |
|---|---|---|---|
| Consulta del propietario | veh_789 pertenece al usuario del JWT. | GET /api/v1/vehiculos/veh_789. | 200 OK; devuelve vehículo e historial. |
| Sin historial | Vehículo propio sin servicios ni mantenimientos. | GET /api/v1/vehiculos/veh_789/historial?pagina=1&limite=20. | 200 OK; servicios y mantenimientos son arreglos vacíos. |
| No existe | No existe veh_noexiste. | GET /api/v1/vehiculos/veh_noexiste. | 404 Not Found. |
| Acceso ajeno | Vehículo pertenece a otro usuario. | GET /api/v1/vehiculos/veh_789 con token de otro cliente. | 403 Forbidden o 404 según política; no filtra datos. |

**Trazabilidad:** `MOD-02`, `FUN-06`, `PRO-06`
