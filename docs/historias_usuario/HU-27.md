# [HU-27] Registrar calificación numérica y reseña del cliente sobre el servicio recibido

**Dado:** Cliente que recibió un servicio.
**Para:** calificar y comentar un servicio finalizado dentro del plazo permitido.
**Que:** compartir mi experiencia y contribuir a la evaluación del proveedor.

**Flujo esperado**
1. El cliente selecciona un servicio finalizado y envía la calificación y reseña.
2. El backend verifica que el servicio pertenezca al cliente y esté finalizado.
3. El sistema valida la escala de calificación y la ventana de 48 horas (RN-08).
4. La calificación se guarda una sola vez y se activa la actualización de reputación.

**Criterios de aceptación**
- [ ] Solo el cliente asociado al servicio puede calificarlo.
- [ ] La calificación debe estar dentro de la escala definida y cumplir el límite de 48 horas desde el cierre.
- [ ] Cada servicio admite una sola calificación por cliente.
- [ ] Una calificación válida queda registrada y disponible para el cálculo de reputación.

**Endpoint:** `POST /api/v1/calificaciones`

**Ejemplo de solicitud**
```json
{
  "solicitudId": "aux_456",
  "puntuacion": 5,
  "resena": "Excelente servicio"
}
```

**Respuesta exitosa**
```json
{
  "exito": true,
  "mensaje": "Calificación registrada",
  "datos": {
    "calificacionId": "cal_001",
    "solicitudId": "aux_456",
    "puntuacion": 5,
    "registradaEn": "2026-10-23T12:00:00-05:00"
  },
  "fechaHora": "2026-10-23T12:00:00-05:00"
}
```

**Notas técnicas:** Endpoint `POST /api/v1/calificaciones` pendiente de confirmar; la regla de 48 horas aparece en el documento base (RN-08). La escala de calificación (ej. 1 a 5) es propuesta y se parametriza en la historia de criterios y escalas. Rutas, campos y mensajes son propuesta del equipo; se confirman en el Inventario de APIs (punto 4).

**Errores específicos de esta historia**

| Código | Cuándo ocurre | Mensaje (`mensaje`) |
|---|---|---|
| 409 Conflict | El servicio ya tiene una calificación del cliente. | El servicio ya fue calificado |
| 422 Unprocessable Entity | Plazo de 48 horas vencido, escala inválida o servicio no finalizado. | No es posible registrar la calificación |

**Requisitos de pruebas**

| Caso | Precondición | Acción exacta | Resultado esperado |
|---|---|---|---|
| Primera calificación dentro de 48 horas | Servicio propio finalizado hace menos de 48 h. | POST /api/v1/calificaciones con puntuacion 1-5. | 201 Created; calificación aceptada |
| Calificación duplicada | El servicio ya fue calificado. | POST /api/v1/calificaciones repitiendo solicitudId. | 409 Conflict; se rechaza sin duplicar el registro |
| Plazo vencido | Han pasado más de 48 horas del cierre. | POST /api/v1/calificaciones. | 422 Unprocessable Entity; la calificación no se acepta |
| Servicio ajeno o no finalizado | El servicio es de otro cliente o no está finalizado. | POST /api/v1/calificaciones. | 403 Forbidden; se rechaza la solicitud |

**Trazabilidad:** `MOD-08`, `FUN-20`, `PRO-20`
