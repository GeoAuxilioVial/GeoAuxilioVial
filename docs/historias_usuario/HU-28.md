# [HU-28] Calcular y publicar el índice de reputación ponderada del proveedor

**Dado:** Usuario que consulta un proveedor.
**Para:** consultar la reputación calculada a partir de las calificaciones recibidas.
**Que:** contar con información resumida para valorar la calidad del servicio.

**Flujo esperado**
1. El sistema recibe una nueva calificación o una solicitud de consulta de reputación.
2. El módulo recupera las calificaciones válidas del proveedor y los criterios configurados.
3. Calcula el índice ponderado conforme a la regla vigente.
4. Publica o devuelve el resultado actualizado para las consultas autorizadas.

**Criterios de aceptación**
- [ ] Solo se consideran calificaciones válidas y asociadas al proveedor correcto.
- [ ] El cálculo aplica los criterios y pesos configurados; si no están definidos, se marcan como pendientes y no se inventan.
- [ ] El resultado publicado corresponde a los datos procesados.
- [ ] Cuando no existan calificaciones, se informa que no hay datos suficientes en lugar de presentar un índice ficticio.

**Endpoint:** `GET /api/v1/proveedores/{proveedorId}/reputacion` ; `PUT /api/v1/proveedores/{proveedorId}/reputacion`

**Ejemplo de solicitud**
```json
{
  "pathParam": {
    "proveedorId": "<valor>"
  }
}
```

**Respuesta exitosa**
```json
{
  "exito": true,
  "mensaje": "Reputación consultada",
  "datos": {
    "proveedorId": "prov_123",
    "indice": 4.6,
    "totalCalificaciones": 18,
    "escala": {
      "minimo": 1,
      "maximo": 5
    }
  },
  "fechaHora": "2026-10-23T12:00:00-05:00"
}
```

**Notas técnicas:** `PUT /proveedores/{id}/reputacion` figura como ruta documentada en el diseño base; la fórmula de ponderación sigue sin definirse (RN-P14). Los criterios y escalas se parametrizan en la historia de criterios de evaluación y escalas de reputación. Rutas, campos y mensajes son propuesta del equipo; se confirman en el Inventario de APIs (punto 4).

**Requisitos de pruebas**

| Caso | Precondición | Acción exacta | Resultado esperado |
|---|---|---|---|
| Proveedor con calificaciones | El proveedor tiene calificaciones válidas. | GET /api/v1/proveedores/prov_123/reputacion. | 200 OK; se calcula y devuelve el índice según la regla vigente |
| Sin calificaciones | El proveedor no tiene calificaciones. | GET /api/v1/proveedores/prov_999/reputacion. | 200 OK; indice=null; mensaje de datos insuficientes |
| Calificación inválida no se incluye | Existe una calificación fuera de escala. | PUT /api/v1/proveedores/prov_123/reputacion. | 200 OK; la calificación inválida no entra en el cálculo |
| Cambio en criterios de evaluación | Los criterios cambiaron en la parametrización. | PUT /api/v1/proveedores/prov_123/reputacion. | 200 OK; el cálculo usa la configuración autorizada vigente |

**Trazabilidad:** `MOD-08`, `FUN-21`, `PRO-21`
