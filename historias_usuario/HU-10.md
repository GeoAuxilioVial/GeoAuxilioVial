# [HU-10] Consultar ubicación y proveedores cercanos

## Historia de Usuario

**Dado:** Cliente que solicita asistencia.  
**Para:** buscar proveedores disponibles cercanos a mi ubicación.  
**Que:** elegir una opción viable según distancia, cobertura y tipo de servicio.

## Flujo esperado

1. El cliente envía coordenadas y tipo de servicio requerido.
2. El backend valida rangos geográficos y autenticación.
3. Filtra proveedores habilitados, disponibles, con cobertura y ubicación reciente.
4. Ordena resultados por distancia estimada y devuelve campos mínimos.
5. Si no hay candidatos, devuelve lista vacía con mensaje claro.

## Criterios de aceptación

### 1. Estructura y lógica del servicio

- [ ] Latitud entre -90 y 90; longitud entre -180 y 180.
- [ ] No se incluyen proveedores inhabilitados, indisponibles o fuera de cobertura.
- [ ] Se aplica el umbral de frescura de ubicación configurado.
- [ ] Sin candidatos se devuelve 200 con datos.proveedores=[] .
- [ ] No se exponen datos personales no necesarios.

### 2. Estructura de la información y contrato JSON

Sobre estándar de respuesta para todas las APIs: `exito` (boolean), `mensaje` (string), `datos` (objeto o `null`) y `fechaHora` (ISO 8601 con zona horaria). El cuerpo no sustituye el código HTTP.

### Endpoint y método HTTP

- `GET /api/v1/proveedores/cercanos?latitud={lat}&longitud={lon}&tipoServicio={tipo}&radioKm={radio}`
- `Content-Type: application/json` en operaciones con body.
- Autenticación: `Authorization: Bearer <JWT>` salvo registro/login.

### Ejemplo de solicitud

```json
{
  "query": {
    "latitud": 7.1193,
    "longitud": -73.1227,
    "tipoServicio": "GRUA",
    "radioKm": 15
  }
}
```

## Notas técnicas

El cálculo de distancia puede usar PostGIS o fórmula geográfica equivalente. El umbral de frescura y la política de radio deben configurarse en MOD-09.

## Requisitos de pruebas

| Caso | Precondición | Acción exacta | Resultado esperado |
|---|---|---|---|
| Candidatos disponibles | Existen proveedores activos dentro del radio con ubicación reciente. | GET /api/v1/proveedores/cercanos?latitud=7.1193&longitud=-73.1227&tipoServicio=GRUA&radioKm=15. | 200 OK; lista contiene solo candidatos elegibles. |
| Sin candidatos | No hay proveedores elegibles en radio. | GET al mismo endpoint con zona sin cobertura. | 200 OK; datos.proveedores=[]. |
| Coordenadas inválidas | Servicio disponible. | GET con latitud=120. | 422 Unprocessable Entity; no ejecuta búsqueda. |
| Ubicación desactualizada | Proveedor con ubicación anterior al umbral permitido. | GET con coordenadas válidas. | 200 OK; proveedor desactualizado no aparece. |
